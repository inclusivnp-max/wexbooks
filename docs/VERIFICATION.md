## Git и воспроизводимость

- Первый коммит сохраняет исходное Android-приложение с настроенной release-подписью.
- Следующий коммит содержит план, правила работы, Backdrop, оформление, motion system и тесты.
- Проверяются `git diff --check`, игнорирование локальных секретов и отсутствие значений паролей в отслеживаемых исходниках.
- Новые полные копии и архивы проекта не создавались. Восстановление исходников — через историю Git.
- Локальные ключи/пароли не публикуются; удалённый репозиторий не настроен.

Готов интерактивный дизайн-прототип с собственным демо-текстом. Импорт, реальный EPUB-движок, Room/DataStore и чтение пользовательских книг описаны следующими этапами в продуктовом плане. Работающий интерфейс не означает, что эти функции уже реализованы.
