# Производительность на Pixel 9 Pro XL

Дата: 25 октября 2026. Android 17 / API 37. USB ADB, без эмулятора.

## Методика

Macrobenchmark 1.5.0 запускает отдельное приложение `.benchmark`: non-debuggable, profileable, тот же release-like код, CompilationMode.None. Холодный старт — 5 повторов; перелистывание — 3 повтора по 12 переходов. Настройки частоты экрана/анимаций телефона не менялись.

База — EPUB-реализация до перехода на общее ReaderCore. Контрольный APK: SHA-256 `304230e64fdb3e76bd67ac9ff04a0f2b9d8577395345587609c8faa4ef120fff`. Итог — ReaderCore, исправленные цвета и облегчённый материал панелей читалки.

## Результаты

| Показатель | До | После |
|---|---:|---:|
| Холодный старт библиотеки, TTID median | 262.88 мс | 276.69 мс |
| EPUB, CPU frame P95 | 15.14 мс | 11.92 мс |
| EPUB, frameOverrun P95 | 4.39 мс | 4.63 мс |
| Нативный TXT, CPU frame P95 | — | 15.33 мс |
| Нативный TXT, frameOverrun P95 | — | 5.79 мс |

В этих выборках старт вырос на 5.3%, CPU P95 EPUB снизился примерно на 21%, overrun P95 изменился на +0.24 мс. Это не обещание отсутствия любых регрессий: пять стартов на одном телефоне не доказывают статистическую эквивалентность. Для нативного TXT исходной сопоставимой реализации не было; напрямую сравнивать его с другим EPUB-корпусом некорректно.

Начальный бюджет нативного CPU P95 — 16.7 мс. Частота 120 FPS для всех сценариев не объявляется достигнутой; положительный overrun на хвостах остаётся направлением дальнейшей оптимизации.

## Что сделано для ограничения нагрузки

- Парсеры работают вне UI-потока, native TextMeasurer — на последовательном worker.
- Кеш ограничен числом и весом; только одна страница предзагрузки.
- Смена темы не инвалидирует геометрию native-страниц.
- Скрытая библиотека отписывается от Room; сохранения позиции объединяются.
- Панели вне viewport текста используют фон бумаги, а не копируют весь WebView/Canvas ради размытия пустого поля.

## Повторение и контроль

```bash
ANDROID_SERIAL=47101FDAS0028Q ./gradlew :benchmark:connectedBenchmarkAndroidTest
python3 tools/check_performance.py benchmark/results/baseline.json benchmark/results/pixel-20261025.json
```

Проверка завершилась exit 0. Пороги: старт не более +15%; CPU P95 EPUB не более +15%; overrun P95 EPUB не более +2 мс; первоначальный native CPU P95 не более 16.7 мс.

Компактные исходные измерения сохранены в `benchmark/results/`. Полные JSON и Perfetto traces — в исключённом из Git `benchmark/build/outputs/connected_android_test_additional_output/`.
