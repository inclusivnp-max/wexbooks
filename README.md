# WexBooks

Android-читалка на Kotlin и Jetpack Compose. Направление: спокойная книжная типографика и iOS-inspired Liquid Glass на элементах управления.

## Сейчас
- Интерактивная основа оформления: библиотека, пустое состояние заметок, настройки вида.
- Собственный демо-текст с изменением размера шрифта, темой и демонстрационной закладкой.
- Настоящий эффект Backdrop 2.0.1: размывается и преломляется захваченный Compose-фон.
- Светлое/тёмное оформление и уменьшение прозрачности; состояние прототипа сохраняется при пересоздании Activity.
- Release-подпись настроена локально. Ключи и пароли исключены из Git.

Импорт, хранение и чтение пользовательских EPUB/FB2/PDF идут следующими этапами. Демо-экран проверяет дизайн, а не заменяет книжный движок.

## Сборка
```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest
./gradlew :app:assembleRelease :app:bundleRelease
```

Для release нужны локальные `keystore.properties` и `keystore/wexbooks-release.jks`. Они уже созданы на текущем компьютере. На другой машине локальную конфигурацию нужно передать отдельно от исходников.

Для UI-тестов на выбранном эмуляторе:
```bash
ANDROID_SERIAL=emulator-5580 ./gradlew :app:connectedDebugAndroidTest
```

История изменений ведётся коммитами Git, без дублирующих копий проекта. Удалённый репозиторий пока не подключён.
